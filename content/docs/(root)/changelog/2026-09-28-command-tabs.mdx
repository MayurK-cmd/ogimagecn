---
title: September 28, 2026 - Shadcn and Prompt Install Tabs
description: Install command blocks gained shadcn CLI and agent prompt tabs.
date: 2026-09-28
---

Install command blocks now offer **shadcn** and **prompt** tabs alongside the
package manager commands, so you can copy a `shadcn` CLI command or a
ready-made agent prompt for any component, contributed by
[@MayurK-cmd](https://github.com/MayurK-cmd).
