## October 3, 2026 - Playground

We added a [Playground](/playground). Pick any block, tweak every prop with a
live Satori preview, then copy the JSX, save the PNG, or grab the install
command for your package manager, contributed by
[@MayurK-cmd](https://github.com/MayurK-cmd).

## October 2, 2026 - Divider Component

We added a [Divider](/docs/components/divider) component: a solid or dashed
rule with an optional centered label and adjustable thickness, contributed by
[@SriVishnu230707](https://github.com/SriVishnu230707).

<ComponentPreviewGrid className="mt-4" names={["divider"]} />

## September 28, 2026 - Shadcn and Prompt Install Tabs

Install command blocks now offer **shadcn** and **prompt** tabs alongside the
package manager commands, so you can copy a `shadcn` CLI command or a
ready-made agent prompt for any component, contributed by
[@MayurK-cmd](https://github.com/MayurK-cmd).

## September 28, 2026 - Scan Redirect Fix

[Scan](/scan) now resolves relative preview assets after redirects, so pages
that bounce through a redirect still show the right images, contributed by
[@SriVishnu230707](https://github.com/SriVishnu230707).

## September 23, 2026 - Blocks and Components

The Open Graph image components you knew are now **[blocks](/docs/blocks)**,
built from new Satori-safe **[components](/docs/components)**.

## September 23, 2026 - Eight More Platform Pages

[Scan](/scan) gained pages for Threads, LINE, Google Chat, TikTok, WeChat,
iMessage, Tumblr and Nextdoor, contributed by
[@MayurK-cmd](https://github.com/MayurK-cmd).

## September 22, 2026 - Mastodon, Snapchat and Signal Previews

[Scan](/scan) now shows how your link looks on Mastodon, Snapchat and Signal,
contributed by [@vansh-nagar](https://github.com/vansh-nagar),
[@MayurK-cmd](https://github.com/MayurK-cmd) and
[@mdsahilnoob](https://github.com/mdsahilnoob).

## September 21, 2026 - Six Platform Pages

[Scan](/scan) gave Google, Microsoft Teams, Reddit, Instagram, Bluesky and
Notion a page of their own, each showing a single preview instead of the full
wall of cards, contributed by [@kuldeeepy](https://github.com/kuldeeepy),
[@MayurK-cmd](https://github.com/MayurK-cmd) and
[@AbhinRustagi](https://github.com/AbhinRustagi).

## September 19, 2026 - Notion and Bluesky Previews

[Scan](/scan) now includes **Notion** and **Bluesky** alongside X, Facebook,
LinkedIn, Slack and Discord. Paste a URL and see exactly how the card renders
on each platform before you share it.

Both contributed by [@mateuscmtropical](https://github.com/mateuscmtropical).

## September 17, 2026 - Scan

We added [Scan](/scan). Paste a URL and see the card the way each platform will
draw it, alongside anything worth fixing.

We also fixed `Showcase`, which threw when its optional `accent` prop was left
out.

Both contributed by [@bhaumikmistry](https://github.com/bhaumikmistry).
