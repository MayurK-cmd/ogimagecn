## Usage

```tsx
import { BrandMark } from "@/components/og/brand-mark";
```

```tsx
<BrandMark src={logoUrl} size={40} radius={8} background="#7c3aed">
  A
</BrandMark>
```

Satori decodes PNG, JPEG, and GIF only. Convert WebP and AVIF logos before passing them in.
