## Usage

```tsx
import { Divider } from "@/components/og/divider";
```

```tsx
<Divider
  color="#a78bfa"
  label="New collection"
  thickness={2}
  variant="dashed"
/>
```

Omit `label` for a single full-width rule. Use `thickness` to set the line width in pixels.

## API Reference

| Prop        | Type                  | Default     |
| ----------- | --------------------- | ----------- |
| `variant`   | `"solid" \| "dashed"` | `"solid"`   |
| `color`     | `string`              | `"#71717a"` |
| `label`     | `string`              | —           |
| `thickness` | `number`              | `1`         |
