## Usage

```tsx
import { GridLines } from "@/components/og/grid-lines";
```

```tsx
<div
  style={{
    display: "flex",
    height: "100%",
    position: "relative",
    width: "100%",
  }}
>
  <GridLines inset={64} color="#44403c" variant="dashed" />
  {/* content */}
</div>
```

## API Reference

| Prop      | Type                  | Default     |
| --------- | --------------------- | ----------- |
| `inset`   | `number`              | `64`        |
| `color`   | `string`              | `"#44403c"` |
| `variant` | `"solid" \| "dashed"` | `"dashed"`  |
